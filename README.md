# MyFood - Milestone 01

Projeto desenvolvido em Java para a disciplina de Programação 2, referente ao Milestone 01 do projeto MyFood.

## Objetivo

Implementar as funcionalidades iniciais do sistema MyFood, contemplando as histórias de usuário até a US 4_2, com compatibilidade com os testes de aceitação fornecidos.

## Conceitos aplicados

- Classes e objetos
- Construtores
- Encapsulamento
- Herança
- Classes abstratas
- Composição
- Listas
- Exceções
- Persistência em arquivo

## Funcionalidades implementadas

- Cadastro de usuários
- Login
- Consulta de atributos de usuários
- Cadastro de empresas
- Consulta de empresas
- Cadastro e edição de produtos
- Listagem de produtos
- Criação e gerenciamento de pedidos
- Persistência em arquivo

## Estrutura do projeto

- `models`: entidades principais do sistema
- `exceptions`: exceção personalizada para regras de negócio
- `services`: classes responsáveis pela persistência e regras do sistema
- `Facade`: classe principal utilizada pelos testes
- `Main`: execução dos testes com EasyAccept

## Como executar

Executar a classe `Main.java` pelo IntelliJ IDEA para rodar os testes de aceitação do projeto.

## Observação

O projeto foi implementado de forma compatível com os testes do EasyAccept disponibilizados para o Milestone 01 do projeto MyFood.
